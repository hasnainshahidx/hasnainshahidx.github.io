Automated Football Data Scraper — Sofascore

Problem
The client needed historical & upcoming match data for 5 major leagues to feed a machine-learning model — but Sofascore has no public API.
Solution
A production pipeline that drives a real browser and captures JSON responses straight from Chrome's network logs via the DevTools Protocol, with retries, auto browser restarts and failure logging.
Result
70+ statistics per match — lineups, referees, standings, team form — in an ML-ready CSV that auto-updates every 8 hours.
